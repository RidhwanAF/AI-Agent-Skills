# Android CLI Reference (Token-Efficient)

## Key Commands
- **Devices & Emulators:**
  ```bash
  android device list
  android emulator list
  android emulator launch <avd_name>
  ```
- **Build & Run:**
  ```bash
  android run
  android build
  ```
- **SDK Inspection:**
  ```bash
  android sdk list
  android sdk install <package_id>
  ```
- **Logcat & Screen:**
  ```bash
  android logcat
  android screenshot <output_path.png>
  ```
